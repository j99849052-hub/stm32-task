# STM32 GPIO 按键输入与上下拉复习

## 先核对理解

1. **按键是一个需要实际接入电路的元件。**它可以接在 GPIO 引脚与 GND 之间，也可以接在 GPIO 引脚与 3.3V 之间；接法要和上拉/下拉方式配套。
2. **输入模式是读取引脚上的电压状态。**STM32把电压判断成低电平 `0` 或高电平 `1`，程序再根据读数执行逻辑。
3. **程序可以用一个输入控制另一个输出。**例如：若 PB0 读到 `0`，就让 PB1 输出高电平。这就是按键控制电路的基本工作方式。

要注意：PB0 读到 `0` 不会自动让 PB1 变高；必须由程序写出这个判断和输出动作。

## 上拉输入：按键接地

```text
STM32内部                         外接按键
3.3V ──[内部上拉电阻]──┬── PB0（输入）
                       └──[按键]── GND
```

- 按键松开：回路断开，内部上拉电阻把 PB0 拉向 3.3V，读到 `1`。
- 按键按下：PB0 经按键连到 GND，读到 `0`。
- 这种接法叫“按下为低”（低电平有效）。

## 下拉输入：按键接 3.3V

```text
外接按键                           STM32内部
3.3V ──[按键]──┬── PB0（输入）
               └──[内部下拉电阻]── GND
```

- 按键松开：内部下拉电阻把 PB0 拉向 GND，读到 `0`。
- 按键按下：PB0 经按键连到 3.3V，读到 `1`。
- 这种接法叫“按下为高”（高电平有效）。

上拉/下拉电阻的作用，是在按键松开、引脚没有被按键接到另一边时，给引脚一个稳定的默认电平。它不是给 LED 或蜂鸣器供电用的。

## 按键控制输出的程序逻辑

```c
// 示意逻辑：假设 PB0 是上拉输入，PB1 是输出
if (读取PB0 == 0)       // 上拉接法下，按下时读到 0
{
    PB1输出高电平();
}
else
{
    PB1输出低电平();
}
```

实际代码会用标准库读取输入状态、设置输出状态；并且通常要加入按键消抖处理，避免机械触点弹跳造成一次按下被读成多次。

## 按键能不能直接和用电器串联？

**可以，若只想让按键像普通开关一样直接控制一个合适的小负载。**例如电池、限流电阻、LED、按键串成闭合回路，按下就亮，松开就灭。此时 MCU 不一定参与，也就不能由程序读取按键状态。

如果希望“按键按下后由 STM32 决定怎么控制”，就把按键接到 GPIO 输入，再由程序控制输出。LED 必须串联限流电阻；蜂鸣器、电机等负载若电流较大，通常要用三极管或 MOSFET 驱动，不能让 GPIO 直接承担超出规格的电流。也不要把按键接法误接成 3.3V 与 GND 之间没有限流的短路。

## 一句话记忆

**按键把引脚电压变成状态；GPIO 输入读取状态；程序作判断；GPIO 输出再控制外部电路。**

## 四脚按键实测记录（2026-10-16）

以下是本次手中这只四脚按键的万用表通断测试结果，距离指引脚之间的间距：

- 相距较远的两个脚：松开时也导通，属于同一组内部触点。
- 相距较近的两个脚：松开时不导通，按下后才导通，分属两组内部触点。

因此，这只按键用来连接 PE2 上拉输入时，可选一对“松开不通、按下才通”的近距离引脚，一脚接 PE2，另一脚接开发板 GND，其余两脚不接。不要把 PE2 和 GND 接到本来就相通的同一组脚上，否则会一直读到低电平。

此脚距规律只记录本次实测的这只按键；其他型号或不同方向放置的按键，仍应先断电，用通断档确认分组。插入面包板后，还要确认不同组没有被面包板内部连通孔提前接在一起。
