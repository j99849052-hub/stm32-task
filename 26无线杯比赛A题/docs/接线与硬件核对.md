# 光照记录仪接线与硬件核对

本表是当前已用固件和模块底板的接线关系。**接口按焊盘编号描述，不能把表格行顺序直接当作从某一观察方向看的左右顺序。** 方形焊盘为1号，应与模块实物引脚核对。

## 模块接口

| 位号 | 焊盘编号 | 网络/用途 |
|---|---|---|
| J3 OLED | 1 / 2 / 3 / 4 | GND / 3V3 / PB6(SCL) / PB7(SDA) |
| J4 光敏 | 1 / 2 / 3 / 4 | 3V3 / GND / DO不接 / PA0(AO) |
| J5 Flash | 1 / 2 / 3 / 4 / 5 / 6 | 3V3 / PA4(CS) / PA6(DO) / GND / PA5(CLK) / PA7(DI) |
| J6 UART | 1 / 2 / 3 | GND / PA9(TX) / PA10(RX) |
| J7 RTC备用电源 | 1 / 2 | VBAT(正) / GND |
| R1 电位器 | 1 / 2 / 3 | GND / PA1滑动端 / 3V3，以底板网络为准 |
| SW1 / SW2 / SW3 / SW4 | 1 | PB0 / PB1 / PB10 / PB11 |
| 四只按键 | 3 | GND；2、4不另外布线 |
| C1 / C2 | 1 / 2 | 3V3 / GND，100nF无极性陶瓷电容 |

串口采用3.3V逻辑：J6的TX接电脑串口模块RXD，J6的RX接模块TXD，共地；接口不提供主电源。

按键1、2本来就在内部连通，3、4本来连通，按下才跨两组接通。GPIO内部上拉，松开为1、按下为0。

模块统一由3.3V供电；主供电沿用ST-Link连接核心板原接口。VBAT是RTC备份输入，不是整机供电，也不是底板3V3输出。

## 尺寸与装配：下单前必须确认

- 底板板框：100mm×95mm；四角安装孔直径3.2mm，孔中心距对应近板边5mm。
- U1/U2：各1×20，针距2.54mm。**目前两排中心距15.24mm，只是候选；还没有1∶1纸样/实物核对。**
- 核心板用户测量约52×22.5mm，排距约15.5mm；不能把粗略尺量值当精确制造尺寸。
- OLED约25.8×25.8mm，背面直出排针，针中心离近侧板边约1.5mm；必须确认实际插向和下方避让。
- Flash约14.5×13.5mm，背面直出排针，离近侧板边约1.5mm；需确认本体朝向。
- 光敏模块竖立：宽约14mm、高约39mm，因弯针本体水平偏移约4mm。按键操作、传感器受光和插拔空间须实物检查。
- 电位器：5kΩ、3296W外形候选；手中长轴版本的封装、针距、孔径和高度仍须实物核对。
- 排母与模块插入后的高度必须足够，不能让核心板底部焊点碰到下方焊点/元件。
- 安装金属螺丝时考虑螺丝头与垫圈直径，避免压住焊盘或碰模块，不仅检查孔径。

## 板子制造前顺序

先确认新增功能→打印100%比例纸样并量100×95mm板框确认比例→实物逐孔、逐模块核对→检查接口方向/电源/孔径→重新铺铜与DRC→确认后才导出生产文件并下单。本次没有生成Gerber或提交订单。
