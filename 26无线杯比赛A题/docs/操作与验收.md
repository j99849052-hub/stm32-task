# 当前版本操作与验收

## 面包板上已经验证的操作

开机短暂显示Light Logger，然后进入实时页。光敏模块遮光时电压增大，光越强电压越小。

| 控件 | 正常功能 |
|---|---|
| PB0／SW1 | 阈值设置与确认；历史界面切换日期筛选 |
| PB1／SW2 | 长按约1秒启动或停止手动记录；停止时短按循环最近三次历史与实时界面 |
| PB10／SW3 | 停止且关闭定时后进入校时；编辑中取消 |
| PB11／SW4 | 停止后进入每日定时设置；编辑中取消 |
| 电位器／R1 | 调整当前选中的阈值、日期或定时字段 |

PB0依次确认强/中分界、中/弱分界，要求前者小于后者。默认源码值0.7V、2.3V；Flash中的有效保存值会覆盖默认值。现场根据传感器实际环境调整。

校时顺序：年→月→日→时→分→秒→预览→确认写入。每项刚进入时保留原值；旋钮变化超过40个ADC计数后才采用当前旋钮位置，首次移动可能跳到绝对位置对应值。

每日定时依次设置开始时分秒、停止时分秒、预览及ON/OFF。开始与停止不能相同，支持跨午夜。ON禁止手动启停；关闭后恢复手动操作。

## 显示与记录

实时页包含当前月日时分秒、Weak/Medium/Strong、REC/STOP、AUTO/MAN、W/M/S累计秒数。右下角A表示光敏ADC原始读数，不是自动模式标志。

历史记录保存开始日期和开始时间，以及弱/中/强三个等级累计时长。只保留最近三条完整记录；第四条完成后淘汰最旧一条。PB0日期筛选依据记录的开始日期。

RTC（Real-Time Clock，实时时钟）使用板上32.768kHz LSE晶振。VBAT保持备份域供电时可断主电源继续计时；主电源和VBAT都断开后不能凭Flash得知断电经过的时间，需要重新校时。

## 收到或更改工程后快速验证

1. 打开完整Keil工程，确认芯片C8T6和AC6，编译无错误。
2. 校准真实当前时间，检查秒正常增加；RESET后时间延续。
3. 遮光、室内光、手机照明，检查三等级和ADC读数变化。
4. 调整两条阈值并确认，检查非法阈值顺序不能提交。
5. 手动开始、改变光照等级、停止，检查分级累计时长和历史开始时间。
6. 完成四次短记录，检查只保留最近三次，日期筛选正常。
7. 设置未来1～2分钟自动开始、停止，检查开启定时后禁止手动冲突；另测跨午夜。
8. 等待串口Storage saved后断主电源再开，检查Storage restored、阈值和三条历史恢复。
9. VBAT保持供电时断主电源，等待一段时间再开，检查RTC连续走时。避免把“恢复了旧时间”当作“断电期间持续计时”。

上述为当前基线验收方法；新PCB需要焊接后重新做整机验收。长时间运行、供电切换及新增功能联调另行验证。
