# 极性的参数理解

## 1. 极性：选择哪种边沿作为计数节拍

用户已经理解并希望保留的表述：

> 以对应电平变化的边沿为计数节拍。

TIM_ExtTRGPolarity = External Trigger Polarity，外部触发极性。Ext 是 External（外部），TRG 是 Trigger（触发），Polarity 是极性。

在这里，“有效”就是：选中的那一种边沿，可以作为送入定时器计数路径的节拍。

```text
引脚电平：0 → 1 → 0 → 1 → 0
边沿种类：  ↑   ↓   ↑   ↓
          上升 下降 上升 下降
```

| 传入参数 | 选中的计数边沿 | 直观理解 |
| --- | --- | --- |
| TIM_ExtTRGPolarity_NonInverted | 上升沿，0→1 | 每次电平由低变高，送入一个计数节拍。 |
| TIM_ExtTRGPolarity_Inverted | 下降沿，1→0 | 每次电平由高变低，送入一个计数节拍。 |

Non-Inverted 是不反相；Inverted 是反相。它们选择输入信号如何被识别，不会主动把外部引脚的电压变高或变低。

当外部触发预分频关闭、PSC=0、定时器已启动且向上计数时，每个通过滤波确认的有效边沿使 CNT 加 1。

- PSC = Prescaler，预分频器；PSC=0 表示该级不分频。
- CNT = Counter，计数器。
- 保持高电平或保持低电平，不会因此一直加 1；这里数的是跳变边沿。
- CNT 加 1 不等于立即执行中断函数。当前常见更新中断用法中，要数到 ARR 后溢出，并满足中断使能与响应条件。
- ARR = Auto-Reload Register，自动重装载寄存器，规定计数边界。

## 2. 滤波：确认这次变化是不是稳定的真变化

ExtTRGFilter = External Trigger Filter，外部触发滤波配置。Filter 是滤波，作用是尽量拒绝输入中的短暂毛刺。

可以这样理解：

> 极性选择“数哪种边沿”；滤波检查“这次变化是否稳定到值得承认”。

启用数字滤波后，不是引脚刚变一下就立即承认变化，而是按指定频率反复采样。连续采到 N 次相同的新电平，才让滤波输出切换到这个新电平；中途变化会打断这次连续确认。

例如滤波输出原来为低电平，设置 N=4：

```text
采样值：0 0 1 1 0 0 0
结果：高电平只连续出现 2 次，没达到 4 次，不承认变高。

采样值：0 0 1 1 1 1 1
结果：连续采到 4 次高电平后，承认输入已经稳定变高。
```

这不是“4 个外部脉冲才计数”，而是对同一段电平作 4 次连续采样确认。过滤后被承认的边沿，再按所选极性和分频设置参与计数。

## 3. 滤波参数的数值怎么理解

ExtTRGFilter 可填 0～15，也就是 0x00～0x0F。每个值是一个配置编号，对应一组“采样频率 + 连续确认次数 N”。

| 举例 | 意义 |
| --- | --- |
| 0x00 | 不启用数字滤波，不作连续 N 次确认。 |
| 0x01 | 以内部时钟频率采样，连续确认 2 次。 |
| 0x03 | 以内部时钟频率采样，连续确认 8 次。 |
| 0x0F | 以 fDTS/32 采样，连续确认 8 次。 |

fDTS 是手册中的滤波/死区时基频率符号，基准由 TIM_ClockDivision 配置；不能用 CNT 的计数频率直接代替它。完整的 16 档取值表见 [ETR 外部触发极性与滤波参数记录](STM32_ETR外部触发极性与滤波参数记录.md)。

- 采样越慢，或需要连续确认的次数越多，稳定性确认所需的时间一般越长。
- 短毛刺更容易被拒绝，但识别延迟也增加，太窄的真实脉冲可能被漏掉；不是越大就永远越好。
- 0x0F 是十进制 15，但不代表 15 毫秒，更不代表 15 次采样。
- 极性参数也要按接口宏填写：NonInverted 对应 0x0000，Inverted 对应 0x8000；不能用裸数字 1 代替 Inverted。

## 一句话复习

**极性：以对应电平变化的边沿为计数节拍。**

**滤波：连续采样确认电平稳定后，才承认这次变化，避免把短毛刺当成有效变化。**

以上是记忆用的功能解释；ETR 输入的极性、预分频、滤波和时基预分频各有配置，不能把它们看成同一个参数。本次只整理学习记录，没有改动工程。
