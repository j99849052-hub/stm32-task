## 实验环境与实现

- 当前学习板：江科大套件 STM32F103C8T6 最小系统板。
- 工程目标：STM32F103C8；标准库宏 `USE_STDPERIPH_DRIVER,STM32F10X_MD`；实际引用启动文件 `Start/startup_stm32f10x_md.s`。
- 工具：Keil MDK；原工程最近一次构建日志记载 Arm Compiler 6.24。
- 输出通道：TIM2 通道 1，默认映射 PA0；GPIO 为复用推挽。
- 输出比较：PWM1、高有效；初始 CCR1=0。
- 时基：PSC=720-1，ARR=100-1，向上计数。按工程的 72 MHz 定时器时钟配置，PWM 频率为 1 kHz。此为代码与配置推算，并非示波器实测结果。
- 呼吸过程：主循环每 10 ms 更新一次 CCR1，数值从 0 递增至 100，再从 100 递减至 0。每段包含 101 次延时，名义呼吸循环约 2.02 秒，另有程序执行开销。
- `PWM_SetCompare1` 是本工程自定义封装，内部调用标准库 `TIM_SetCompare1(TIM2, Compare)`。
- 原代码未主动开启 CCR 预装载；相关复习图保留这一功能的学习说明，但本次未擅自修改已完成的代码。

## 打开与复现

1. 将整个 `01_原工程/PWM LED` 目录放到可读写位置，打开其顶层 `Project.uvprojx`，不要单独打开历史备份中的工程。
2. 确认 Keil 已安装所需编译器和 STM32F1 器件包。原工程配置使用 `Keil.STM32F1xx_DFP 2.4.1`。
3. 使用实际下载器连接目标板，核对电源、地和输出引脚。程序配置 PA0 输出 PWM；LED 应串联合适的限流电阻，具体亮暗方向由实际接法决定。本次未凭视频文件名推断 LED 电阻值或极性接法。
4. main.c 同时调用 OLED 初始化：软件通信线为 PB8/PB9，程序将 PB7/PB6 分别设为模块供电高电平和低电平。这里记录原代码接法，不把 GPIO 供电方式当成所有模块都可通用的方案。若仅复现呼吸灯，应先理解并核对这一段初始化，不要忽略其存在。
5. 在自己的环境重新构建、下载并观察 LED 周期性渐亮渐暗。工程仍使用标准外设库，不与 HAL 初始化接口混用。
