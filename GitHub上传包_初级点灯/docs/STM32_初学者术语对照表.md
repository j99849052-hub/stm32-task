# STM32 初学者术语对照表

这份文档用于配合 STM32 入门学习。默认读者是有一些 C/C++ 基础、刚开始接触 STM32 的初学者。

## 一、先建立整体认识

### STM32

STM32 是意法半导体（ST）公司生产的一系列**微控制器**。微控制器可以理解为一台很小的、专门控制硬件的电脑，里面包含处理器、存储器、定时器、串口、输入输出接口等。

你写的程序会被编译后下载到 STM32 芯片里运行。它不像电脑程序那样依赖 Windows 窗口，而是直接控制 LED、按键、电机、传感器等硬件。

### MCU

MCU 是 Microcontroller Unit 的缩写，中文是“微控制器”。STM32 就是一类 MCU。

看到“选择 MCU 型号”，就是要选择开发板上实际使用的芯片型号，例如 STM32F103C8T6、STM32F407ZGT6。型号必须和开发板一致。

### 开发板

开发板是把 MCU、电源、晶振、下载接口、LED、按键等放在一块电路板上，方便学习和实验的板子。正点原子的 STM32 板就是一种开发板。

### 固件

固件是运行在芯片内部的程序。你用 C 写的 STM32 工程，编译并下载后，就成为开发板上的固件。

### RAM / SRAM

RAM 是 Random Access Memory 的缩写，中文是“随机存取存储器”。可以把它理解为程序运行时的临时工作区：CPU 能较快地读写里面的数据，但断电后内容通常会消失。

STM32 里常见的是 SRAM（Static Random Access Memory，静态随机存取存储器）。程序运行时的变量、函数调用过程中的临时数据和栈通常会用到 SRAM。RAM 是一大类存储器名称，SRAM 是其中一种；在 STM32 入门语境里，大家常把芯片内部的 SRAM 简称为 RAM。

与它相对，Flash（闪存）通常用来保存程序，即使断电，内容也能保留。简单记：**Flash 放需要长期保存的程序，RAM/SRAM 放运行时临时使用的数据。**

## 二、软件工具

### STM32CubeMX

STM32CubeMX 是 ST 提供的图形化配置工具。它可以帮助你配置：

- 使用哪些引脚；
- 哪些引脚是输入或输出；
- 定时器和 PWM 参数；
- 串口参数；
- 时钟频率；
- 使用哪个软件库。

配置完成后，CubeMX 会自动生成一个工程框架。你仍然需要在代码中补充具体功能。

### Keil MDK / Keil

Keil 是 STM32 常用的开发软件，主要负责：

- 打开工程；
- 编译 C 代码；
- 把程序下载到开发板；
- 调试程序。

比赛要求中的“Keil MDK5”通常指 Keil 的第五代开发环境。它不是 C 语言本身，而是写、编译和下载 STM32 程序的软件。

### 编译

编译就是把人能读懂的 C 源代码转换成芯片能执行的机器代码。编译通过只说明代码语法和工程配置基本正确，不代表已经在开发板上运行成功。

### 下载 / 烧录

下载或烧录是把编译得到的程序写入 STM32 的内部闪存。下载后，开发板重新上电通常就能运行这个程序。

### ST-Link

ST-Link 是给 STM32 下载程序和调试用的工具。部分开发板已经板载 ST-Link，部分开发板需要单独购买下载器。

### HAL 库

HAL 是 Hardware Abstraction Layer 的缩写，中文是“硬件抽象层”。它是一套 ST 官方提供的 C 函数库，让你不用直接操作复杂的寄存器，就能调用类似下面的函数控制硬件：

```c
HAL_GPIO_WritePin(GPIOA, GPIO_PIN_0, GPIO_PIN_SET);
HAL_Delay(500);
```

HAL 是一种外设库。它把许多底层寄存器操作封装成函数，初学时可以通过函数配置和控制外设。

注意：你现在跟随的江科大课程主要使用 STM32 标准外设库（SPL），它和 HAL 是两套不同的库，函数名和工程配置不能直接混用。学到的 GPIO、时钟、定时器等硬件原理可以互相迁移；当前先跟课程把标准外设库的点灯和 GPIO 学扎实即可。

### CMSIS

CMSIS 是 ARM 提供的一套微控制器软件接口规范。它经常出现在 STM32 工程文件中。初学阶段只需要知道它提供了内核和芯片软件的基础接口，不需要专门深入研究。

## 三、GPIO 和电平

### GPIO

GPIO 是 General-Purpose Input/Output 的缩写，中文是“通用输入输出”。它是 STM32 连接外部电路的基本引脚。

- 配置为输出：芯片控制 LED、蜂鸣器等；
- 配置为输入：芯片读取按键、开关等。

### 引脚 / Pin

引脚是芯片或开发板上的电气连接点。常见写法是 `PA0`、`PB1`、`PC13`：

- `P` 表示端口（Port）；
- `A/B/C` 表示端口组；
- 数字表示该组中的第几个引脚。

例如 `PC13` 表示 C 端口的第 13 号引脚。

### 高电平和低电平

- 高电平（High）：通常接近 3.3 V；
- 低电平（Low）：通常接近 0 V。

对 GPIO 来说，输出高或低就是让引脚输出相应电压。注意：有些开发板的 LED 是“低电平点亮”，所以不能只凭高低电平名称判断 LED 是否亮，要看原理图或例程。

### 推挽输出

推挽输出是一种常用的 GPIO 输出方式，可以主动输出高电平和低电平。控制 LED 时一般选择推挽输出。

### 上拉和下拉

上拉或下拉是给输入引脚一个默认状态，避免按键松开时电平漂浮不稳定。按键电路常会用到内部上拉或下拉。

### 消抖

机械按键按下或松开时，触点会在很短时间内快速弹跳，芯片可能误认为按了很多次。消抖就是通过延时、计时或状态判断，确保一次实际按键只被识别为一次。

## 四、定时器和 PWM

### 定时器 / TIM

定时器是芯片内部可以按照固定时间计数的硬件模块。STM32 中常写成 `TIM1`、`TIM2` 等。

它可以用于：

- 精确延时；
- 周期任务；
- 产生 PWM；
- 测量输入信号。

### PWM

PWM 是 Pulse Width Modulation 的缩写，中文是“脉冲宽度调制”。它让引脚快速地在高、低电平之间切换，通过改变高电平所占的时间比例来控制平均效果。

例如 LED：

- 占空比小，平均亮度低；
- 占空比大，平均亮度高。

### 占空比

占空比是一个周期内高电平持续时间的比例。例如占空比 50% 表示一半时间为高电平，一半时间为低电平。

### 呼吸灯

呼吸灯就是让 LED 的亮度逐渐变亮、再逐渐变暗。通常通过逐步改变 PWM 占空比实现。

### 通道 / Channel

一个定时器通常有多个输出通道，例如 `TIM2_CH1` 表示定时器 2 的通道 1。PWM 必须配置到支持定时器通道的具体引脚上。

## 五、串口通信

### UART

UART 是 Universal Asynchronous Receiver/Transmitter 的缩写，中文是“通用异步收发器”。它是一种让 STM32 和电脑、另一个芯片互相发送文字或数据的通信方式。

常用信号线：

- TX：发送（Transmit）；
- RX：接收（Receive）；
- GND：地线。

连接时通常是 TX 接对方 RX，RX 接对方 TX，GND 共地。

### USART

USART 是 UART 的扩展版本，支持更多同步或异步模式。STM32 工程里经常显示 `USART1`、`USART2`。在本次基础串口任务中，可以先把它当作 UART 使用。

### 波特率

波特率是串口通信速度，例如 9600、115200。电脑串口助手和 STM32 必须设置相同的波特率，否则收到的内容会乱码。

### USB-TTL 模块

USB-TTL 模块把电脑的 USB 接口转换成串口的 TX、RX、GND 信号。常见芯片有 CH340、CP2102。它不是下载器，主要用于串口通信。

### 中断

中断是芯片正在执行主程序时，某个事件发生后暂时停下主程序，先去处理这个事件，处理完再回来继续执行。

例如收到一个串口字符时，可以触发中断，而不必一直等待。

### DMA

DMA 是 Direct Memory Access 的缩写，中文是“直接存储器访问”。它可以让外设和内存之间自动搬运数据，减少 CPU 参与。

DMA 属于进阶内容。先用普通串口收发完成基础任务，再考虑 DMA。

## 六、常见外设

### I2C

I2C 是一种只需要少量线路的芯片间通信协议，常用于连接 OLED、温度传感器、IMU 等。

常见两根信号线：

- SCL：时钟线；
- SDA：数据线。

### SPI

SPI 是另一种芯片间通信协议，速度通常较快，常用于屏幕、存储器和传感器。初级 GPIO、PWM、UART 任务不需要 SPI。

### STM32 片上资源 / 外设缩写速查

下面这些名称指芯片内部不同的硬件模块或功能。可以把它们理解成芯片自带的“工具”：程序配置好后，就能用来读按键、发串口数据、定时或和传感器通信。表中的用途用开发板上的实际事情来解释。

| 缩写 | 英文全称 / 中文 | 实际上能做什么 |
|---|---|---|
| NVIC | Nested Vectored Interrupt Controller，嵌套向量中断控制器 | 管理“突发事件”的优先级。例如串口收到数据或定时器到点时，让 CPU 暂停当前流程先处理事件。 |
| SysTick | System Tick Timer，系统滴答定时器 | 提供周期性节拍，常用于系统计时或操作系统的时间基准；HAL 的延时功能也会用到系统时基。 |
| RCC | Reset and Clock Control，复位和时钟控制 | 打开外设的时钟、配置芯片运行节拍；外设时钟没打开时，GPIO、串口等通常无法正常工作。 |
| GPIO | General-Purpose Input/Output，通用输入输出 | 把引脚设为输入读取按键，或设为输出控制 LED、蜂鸣器等。 |
| AFIO | Alternate Function I/O，复用功能输入输出 | 在 STM32F1 上配置引脚复用和部分引脚映射。例如把某个定时器或串口功能换到可用的引脚上。 |
| EXTI | External Interrupt/Event Controller，外部中断/事件控制器 | 引脚电平变化时通知芯片。例如按键按下后触发一次中断，而不是让程序一直反复检查按键。 |
| TIM | Timer，定时器 | 按设定时间计数，可用于周期任务、PWM 调光、测量脉冲或产生定时中断。 |
| ADC | Analog-to-Digital Converter，模数转换器 | 把传感器输出的模拟电压读成数字值，例如读取电位器位置或电池电压。 |
| DMA | Direct Memory Access，直接存储器访问 | 让外设数据自动搬进或搬出内存，减少 CPU 一个字节一个字节处理的工作；常用于大量串口或 ADC 数据。 |
| USART | Universal Synchronous/Asynchronous Receiver/Transmitter，通用同步/异步收发器 | 通过 TX/RX 与电脑或其他模块收发数据；异步串口是初学最常用的方式。 |
| I2C | Inter-Integrated Circuit，集成电路间总线 | 用两根信号线 SCL/SDA 和 OLED、传感器等器件通信。 |
| SPI | Serial Peripheral Interface，串行外设接口 | 用时钟和数据线快速传输数据，常连接屏幕、Flash 或传感器。 |
| CAN | Controller Area Network，控制器局域网 | 让多个控制器在抗干扰的总线上交换数据，常见于汽车和机器人控制系统。 |
| USB | Universal Serial Bus，通用串行总线 | 让设备通过 USB 线连接电脑；具体芯片可能只支持设备功能，能力依型号而不同。 |
| RTC | Real-Time Clock，实时时钟 | 在主程序暂停或低功耗时仍可计时，常用于时钟、日历和定时唤醒。 |
| CRC | Cyclic Redundancy Check，循环冗余校验 | 给一段数据算出校验值，用来检查通信或存储的数据是否意外出错。 |
| PWR | Power Control，电源控制 | 配置低功耗模式、唤醒等电源相关功能，帮助设备省电。 |
| BKP | Backup Registers，备份寄存器 | 在特定供电条件下保存少量关键数据，例如重启后仍要保留的标记或配置。 |
| IWDG | Independent Watchdog，独立看门狗 | 程序定期“喂狗”；若程序卡死、没按时喂狗，看门狗会复位芯片，让设备重新启动。 |
| WWDG | Window Watchdog，窗口看门狗 | 也用于发现程序跑飞并复位；喂狗必须落在规定时间窗口内，过早或过晚都算异常。 |
| DAC | Digital-to-Analog Converter，数模转换器 | 把程序里的数字值转换成模拟电压输出，例如生成简单的电压波形。 |
| SDIO | Secure Digital Input/Output，安全数字输入输出接口 | 通过专用接口和 SD 卡等器件传输数据，可用于文件或数据记录；是否具备取决于芯片型号。 |
| FSMC | Flexible Static Memory Controller，可变静态存储控制器 | 让芯片像访问内存一样连接外部 SRAM、NOR Flash 或并行屏幕，减少逐根控制时序的工作。 |
| USB OTG | USB On-The-Go，USB 主机/设备切换功能 | 让支持该功能的芯片按场景作为 USB 设备或 USB 主机；例如设备连电脑，或主机连接 U 盘。 |

**对你当前任务的优先级：**先掌握 GPIO、RCC、TIM、USART 和 NVIC/EXTI 的大致作用；ADC、DMA、I2C、SPI 等遇到相应实验再学。这个表是 STM32 家族通用速查表，不代表 STM32F103ZET6 一定包含或引出了每一项功能；实际支持情况以芯片数据手册、CubeMX 中该型号可选项和开发板电路为准。

### OLED

OLED 是一种小型显示屏。比赛高级任务中，它被用来显示 IMU 计算出的姿态角。它通常通过 I2C 或 SPI 与 STM32 通信。

### IMU

IMU 是 Inertial Measurement Unit 的缩写，中文是“惯性测量单元”。常见 IMU 包含加速度计和陀螺仪，例如 MPU6050、BMI088。

它可以测量运动和旋转。通过算法可以计算 Roll、Pitch、Yaw；初学阶段先掌握基础 GPIO、定时器和串口，再回头学习 IMU 更容易。

### Roll、Pitch、Yaw

这是描述物体姿态的三个角度：

- Roll：横滚角；
- Pitch：俯仰角；
- Yaw：偏航角。

## 七、实时系统和操作系统

### FreeRTOS

FreeRTOS 是一种用于微控制器的实时操作系统。它允许把程序拆成多个任务，例如串口任务、传感器任务、显示任务。

“实时”不只是运行得快，而是要求任务在规定时间内得到响应。

本次高级电控任务中的 FreeRTOS 可以放到比赛后学习。初级和中级任务不需要它。

### 任务 / Task

在 FreeRTOS 中，任务是一个独立运行的程序功能，例如“串口收发任务”。普通 `while (1)` 循环不等同于 FreeRTOS 任务。

## 八、算法和机器人相关词

### ROS / ROS 2

ROS 是 Robot Operating System 的缩写，中文常称“机器人操作系统”。它主要运行在 Ubuntu 等电脑系统上，用于机器人程序之间的通信和工具集成。

ROS 2 是较新的版本。它和 STM32 HAL 不是同一套技术：STM32 负责底层控制，ROS 2 通常运行在电脑或更强的机器人主机上。

### turtlesim

turtlesim 是 ROS 里的一个教学仿真程序。屏幕上会显示一只小海龟，可以通过键盘控制它移动，用来验证 ROS 2 是否安装成功。

### OpenCV

OpenCV 是一个开源计算机视觉库，常用于读取摄像头、处理图像、识别颜色或形状。它主要运行在电脑上，不是 STM32 GPIO 控制的必需组件。

### YOLO

YOLO 是一种目标检测算法，可以在图像中识别物体并给出物体所在的矩形框。截图中的神经网络识别校徽任务属于算法方向。

## 九、硬件与电路术语

### Multisim

Multisim 是电路仿真软件。它可以在电脑中搭建电源、电阻、三极管、MOSFET 等电路，并观察电压和电流波形。本次 NMOS/PMOS 任务可以先做仿真，不必购买 24 V 功率器件。

### MOSFET

MOSFET 是一种场效应晶体管，常用于电子开关和电机驱动。它有三个主要端子：

- G：栅极，控制开关；
- D：漏极；
- S：源极。

### NMOS 低侧开关

NMOS 通常放在负载和地之间，称为低侧开关。给栅极合适的电压后，NMOS 导通，负载获得电流。

### PMOS 高侧开关

PMOS 通常放在电源和负载之间，称为高侧开关。它的驱动逻辑和 NMOS 不同，电路设计更容易出错，因此适合先做仿真。

### 电阻限流

LED 不能直接接在电源上，通常要串联电阻限制电流。常用 220 Ω 或 330 Ω。没有限流电阻可能烧坏 LED 或 GPIO。

## 十、代码和工程文件名

### `main.c`

主程序文件，通常包含 `main()` 函数和主循环。你会在这里调用初始化函数并安排主要流程。

### `gpio.c` / `gpio.h`

GPIO 初始化代码和相关声明。CubeMX 通常自动生成这些文件。

### `tim.c` / `tim.h`

定时器初始化代码。配置 PWM 后通常会出现这些文件。

### `usart.c` / `usart.h`

串口初始化代码和相关声明。

### `.ioc` 文件

CubeMX 的工程配置文件。它记录芯片型号、引脚、时钟和外设配置。提交 STM32 工程时通常应该保留它。

### `HAL_Init()`

初始化 HAL 库和部分基础硬件。一般在 `main()` 的开头调用。

### `SystemClock_Config()`

配置系统时钟。时钟可以理解为芯片运行的节拍来源，定时器、串口和延时都可能依赖它。

### `MX_GPIO_Init()`、`MX_TIMx_Init()`、`MX_USARTx_UART_Init()`

这些是 CubeMX 自动生成的外设初始化函数，分别用于初始化 GPIO、定时器和串口。

### `while (1)`

STM32 裸机程序通常会在这里持续执行主要工作。因为单片机需要一直运行，所以主循环一般不会结束。

## 十一、电控入门的学习优先级

你目前只需要按下面顺序掌握：

1. C 语言基础：变量、函数、`if`、`for`、`while`；
2. STM32、开发板、MCU 和工程结构；
3. GPIO：引脚、输入输出、高低电平；
4. 按键读取与消抖；
5. 定时器和 PWM；
6. UART、TX、RX、波特率；
7. 根据当前课程学习标准外设库（SPL）；以后需要使用 HAL 工程时，再学习 HAL 和 CubeMX 的配合；
8. 有余力再学习 Multisim；
9. DMA、IMU、OLED、FreeRTOS、ROS、YOLO 放到后续阶段。

遇到不懂的英文缩写时，先回到这份表查含义，再看代码。不要因为看到 DMA、FreeRTOS 或寄存器就停下整个学习计划。
